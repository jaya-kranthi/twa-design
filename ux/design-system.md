# Design System — TWA Weather Data Marketplace
_Canonical, framework-neutral component reference. Every feature build ticket (whatever FE stack stack-picker chooses) must match these patterns. Generated by design-system from tokens.json + design-recommendations.md._

> Edit hand-tuned blocks inside `<!-- minfy: do-not-regenerate -->` fences; they survive regeneration.

## Foundations

- **Color:** see `tokens.css`. Cool-slate canvas, deep-teal accent, amber premium accent (sparing), muted semantic colors, 8-hue data-viz ramp. Light + dark, both WCAG 2.2 AA.
- **Type:** Geist (display/heading), Inter (body), Geist Mono (IDs/versions/keys/metrics, `tabular-nums`). Scale: display 32 / h1 24 / h2 20 / h3 17 / body 15 / body-sm 14 / caption 13.
- **Spacing:** 4px base; 8pt rhythm. Compact density on tables/queues, spacious on onboarding/empty.
- **Radius:** controls 6px, cards 8px, large surfaces 12px, badges/table chips 4px. No pill except avatar/toggle.
- **Elevation:** `--shadow-sm` resting cards, `--shadow-md` popovers/drawers, `--shadow-lg` modals. Borders do most of the structural work (low-shadow, instrument-like).
- **Motion:** 120–260ms, `--ease`. Skeletons for lists/dashboards/detail; spinners only inside async buttons. Honors reduced-motion.
- **Focus:** every interactive element shows `--shadow-focus` ring on `:focus-visible`. Never remove outlines without a token-based replacement.

## Components

### Buttons (`.btn`)
Variants: `primary` (accent bg/accent-fg), `secondary` (surface + border), `ghost` (transparent, hover surface-2), `danger` (danger bg), `premium-outline` (amber border, for upgrade affordances). Sizes: `sm` (28px), `md` (36px), `lg` (44px). States: hover (accent-hover), `:focus-visible` ring, active (translateY 1px), disabled (60% opacity, no pointer), loading (spinner + disabled, label retained). Min target 44px on touch.

### Inputs & forms
Label (always visible) · input (border, 6px radius, focus ring) · helper text (caption, fg-subtle) · inline error (danger, with icon, below field) · success affordance where relevant. Submit disabled until valid. Error placement: inline per-field + summary banner on submit failure. Required marked with `*` + `aria-required`. See `forms.md` per-form rules.

### Badges / status pills (`.badge`)
Tinted bg-subtle + matching fg + leading dot. Never color-only — always dot + text. Standard sets:
- **Org status:** Pending (warn) · Active (success) · Suspended (danger) · Read-only/Expired (fg-muted).
- **Dataset lifecycle:** Draft (fg-muted) · Published (success) · Deprecated (warn) · Archived (neutral).
- **Member:** Pending invite (warn) · Active (success) · Deactivated (fg-muted).
- **Subscription:** Active (success) · Renewing-soon (warn) · Expired/Grace (danger-subtle) .
- **Entitlement:** Entitled (success) · Not in plan (fg-muted, lock icon) · Limit reached (warn).
- **Version:** `v3` mono chip; current version carries an amber star.

### Tables (`.table`)
Sticky header, sortable column headers (aria-sort), row hover, zebra optional, row-level kebab actions, bulk-select checkbox column where bulk is in scope (none in v1), pagination footer (page size 20, max 100), density toggle (comfortable/compact), per-column alignment (numbers right + mono). Empty/loading(skeleton rows)/error(retry) states required.

### Cards / KPI tiles (`.card`, `.tile`)
Card: header (title + optional action) / body / optional footer — no card-in-card. KPI tile: label + big mono value + delta (▲/▼ with success/danger) + sparkline (data-viz) + "as of <ts>" caption + drill-through on click.

### Navigation
- **App-shell:** top bar (logo · global search · role switcher · 🔔 bell · avatar menu) + left sidebar (role-aware primary nav, active item highlighted) + main region with breadcrumbs on deep routes.
- **Sidebar nav item:** icon + label + optional count badge; active = accent-subtle bg + accent fg + left rule.
- **Account/Settings/Sign-out:** avatar dropdown only.

### Overlays
- **Drawer/sheet (right):** create/edit forms (member, plan, dataset metadata). Header + scrollable body + sticky footer actions.
- **Dialog (`<dialog>`, center):** destructive confirms (delete, revoke, suspend, archive) — focus-trapped, Esc + backdrop dismiss, explicit confirm button.
- **Popover:** notifications panel, key-reveal, column menu.
- **Toast:** bottom-right, success/error/info, auto-dismiss 4s, routes into notification history.

### Empty / first-run states
Line icon/illustration + headline + one-line value prop + single primary CTA. Used to *sell*: e.g. empty catalog for a fresh org explains the marketplace and points to "Browse datasets"; no-members points to "Invite your team".

### Loading states
Skeleton shimmer for catalog grid, tables, dashboard tiles, detail panels. In-button spinner for submits. Never a full-page blank spinner for list screens.

### AI surface — NL search (`ai-ux-patterns`)
- **Input:** search field with a prompt-hint placeholder ("Try: rainfall data for the Caribbean in 2023") + an example-chips row on focus (**inputs** pattern).
- **Identity:** a discreet "✦ Interpreted by AI" marker on the resolved-filter row (**identifiers**) — never a chat avatar.
- **Transparency:** the AI's output renders as **editable filter chips** (category/region/time/tags) above normal catalog results — user can remove/adjust any chip; results update deterministically (**trust-builders**).
- **Governors:** "Clear" + "Edit filters" + a quiet "Searched as keywords instead" note on low-confidence/error fallback. No streaming, no chat thread, no AI authority over results.

## Token → utility map
Use `bg-surface`, `text-fg`, `text-fg-muted`, `border-border`, `bg-accent text-accent-fg`, `bg-accent-subtle text-accent-subtle-fg`, `ring`-based focus, `rounded-md`, `shadow-sm/md/lg`, `font-display/sans/mono`. Do not hardcode hex — always the token.
